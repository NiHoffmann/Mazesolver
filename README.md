# Mazesolver for lego nxt
Using Gyro & Colorsensor

0.Clibrate gyro sensor, read node/path/goal colors

1.Drives through maze and mapps node structure

2.Return to starting node

3.Solves for fastest Path and drvies through maze

lego color sensors dont work all that well, so this works best around 9-12am and with natural light, to get a better light spectrum and have easier color readings.

required software:

eclipse,jdk,lejos nxj 0.9,nxt drivers
